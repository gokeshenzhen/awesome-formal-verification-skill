# Experiment boundaries

Use the installed formal-verification skill and only the supplied design and
artifacts. Do not read other experiments, evaluator material, historical agent
sessions, alternative skills or external project sources. Keep your output in
/work. Do not launch subagents, install tools, or change the client, model or
reasoning settings.

This stage permits analysis and proposed verification changes, not new proof
execution or DUT/environment changes. No new proof tool is mounted. A proposed
assertion is not a proved fact.

For formal artifact discovery, prefer TraceWeave get_formal_paths. Do not send
formal logs to simulation-log analysis. The supplied read-only attachment, if
it contains values, is another available representation of the same evidence;
it does not require re-querying every value. Keep uncertainty and missing data
visible. Choose your own reasoning and reporting structure.
